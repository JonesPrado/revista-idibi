Idibi — versão HTML simples

Abra index.html diretamente no navegador. A pasta não precisa de npm, React,
TypeScript ou servidor: textos, JavaScript, estilos, fontes e imagens estão
incluídos aqui.

Como explorar:
- Cada página de leitura ocupa uma tela inteira, sem rolagem interna. Textos
  longos são divididos em viradas. Use o índice, as setas e o controle de
  progresso para navegar manualmente.
- No celular, deslize para a esquerda ou direita para virar a página.
- Clique em uma foto para ampliá-la; use as setas na tela ou do teclado para
  percorrer as imagens.
- Os gráficos são feitos em HTML e CSS, nas cores vinho e azul-claro da Idibi.
  Clique nas barras e na legenda para destacar os valores, ou use “Rever
  animação” para vê-los novamente; alguns gráficos também têm tabelas.

Arquivos principais:
- index.html: estrutura da revista
- styles.css: identidade visual e animações
- app.js: navegação, capítulos, gráficos e ampliador de fotos
- content.js: conteúdo exportado dos capítulos atuais
- assets/: fotos, texturas, logo e fontes locais
